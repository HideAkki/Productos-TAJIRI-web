# Productos Tajiri

Proyecto web con Next.js, Tailwind CSS, Framer Motion y Lucide React.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm start`
- `npm run lint`

## Notas

Esta es una configuración inicial con el App Router de Next.js y un ejemplo de animación con Tailwind y Framer Motion.
